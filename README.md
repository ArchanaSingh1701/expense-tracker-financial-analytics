Expense Tracker \& Financial Analytics SystemsvgA full-stack web application built with Java, Spring Boot, MySQL, HTML, CSS, and JavaScript for managing personal income and expenses and visualizing financial data through an interactive dashboard.📌 Project OverviewsvgThe Expense Tracker allows users to record and manage their financial transactions while providing a clear monthly overview of their income, expenses, balance, and savings.The application also provides analytics through charts and allows users to manage transaction categories.✨
