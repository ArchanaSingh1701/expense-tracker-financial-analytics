Expense Tracker \& Financial Analytics System





A full-stack web application built with Java, Spring Boot, MySQL, HTML, CSS, and JavaScript for managing personal income and expenses and visualizing financial data through an interactive dashboard.



📌 Project Overview





The Expense Tracker allows users to record and manage their financial transactions while providing a clear monthly overview of their income, expenses, balance, and savings.



The application also provides analytics through charts and allows users to manage transaction categories.

📊 Dashboard





The dashboard provides a monthly financial summary with visual analytics.



Summary Cards





Total Income – total income for the selected month

Total Expenses – total expenses for the selected month

Balance – income minus expenses

Total Savings – current financial savings

Transactions – number of recorded transactions

Charts





Expenses by Category – doughnut chart showing how expenses are distributed

Income vs Expenses – bar chart comparing monthly income and expenses
